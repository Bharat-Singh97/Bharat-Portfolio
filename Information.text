Step 1.6 — Understand App.jsx
Sabse pehle code ke 5 important parts samjho.
1. Import statements
import { useState } from 'react'
import heroImg from './assets/hero.png'
import reactLogo from './assets/react.svg'
import viteLogo from './assets/vite.svg'
import './App.css'


Code	Meaning
useState	React Hook, component mein changing data manage karne ke liye
heroImg	Image file ko import karke variable mein store karta hai
reactLogo, viteLogo	Starter page par logos dikhane ke liye
App.css	Is component ki styling import karta hai
Portfolio banate waqt hum unused starter images aur imports hata denge.
2. React component
function App() {
  const [count, setCount] = useState(0)

  return (
    <>
      {/* UI goes here */}
    </>
  )
}


- function App() ek JavaScript function hai.
- React mein is tarah ke function ko component kehte hain.
- return batata hai ki browser mein kaunsa UI render karna hai.
- <>...</> ek Fragment hai. Ye multiple JSX elements ko group karta hai bina extra HTML element banaye.
3. State aur counter
const [count, setCount] = useState(0)


Is line ko parts mein samjho:
- count — current value.
- setCount — value update karne ka function.
- useState(0) — initial value 0 rakhta hai.
Button mein:
onClick={() => setCount((count) => count + 1)}


Button click hone par count ek se badhta hai aur React UI ko update karta hai.
Portfolio mein hum React state ka use zaroorat ke hisaab se karenge, jaise mobile menu ya interactive components ke liye.
4. JSX kya hai?
<h1>Get started</h1>
<p>Edit src/App.jsx and save to test HMR</p>


Ye JSX hai: JavaScript ke andar HTML-jaisa syntax, jisse React UI describe karta hai.
Dhyan do: JSX mein CSS class dene ke liye className use hota hai, class nahi.
5. Export
export default App


Isse doosri file, jaise main.jsx, App component ko import karke render kar sakti hai.
